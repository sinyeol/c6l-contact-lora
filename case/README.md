# C6L 버튼 케이스 설계툴

Unit C6L + 배터리(99×65×12) + 3버튼 PCB(66.04×22.352) + 패널형 USB-C(JRC-C009)를 담는 3D 프린트 케이스. 슬라이더와 평면도 드래그로 바꾸면 3D·평면·단면·부품표·경고가 바로 바뀌고, STL 을 브라우저에서 바로 받는다. Fusion 에서도 같은 형상을 B-rep 으로 만들 수 있다.

- GitHub Pages(main): https://sinyeol.github.io/c6l-contact-lora/case/
- LAN(109 사용자 서비스 `c6l-case-web`, 109 작업 폴더를 그대로 서빙 — 고친 즉시 보임): http://192.168.1.109:8817/
- 직접 열기(ES 모듈·WASM 이라 `file://` 로는 안 열림):

```bash
python3 -m http.server 8817 -d case
```

## 구조 (위 → 아래)

뚜껑·바닥 결합(`JOINT`, 셀렉트): **끼움형**(기본) = 통이 옆면 전체를 갖고 뚜껑·바닥은 통 윗·아랫구멍에 끼우는 판 — 옆면에 이음선이 없다. **적층형** = 외피를 높이(`SEAM_H`, 뚜껑 밑면)로 잘라 쌓는다 — 옆면에 이음선 2줄, 바닥은 벽(`SEAM_H`)이 있는 트레이, 손가락 홈은 이음선의 높은 쪽 부품에(바닥이 낮으면 통). 끼움형은 판 귀퉁이 R(`PLATE_R` 4.6, 평면 — 통 구멍도 같은 R)과 판 둘레 테두리 R(`EDGE_R` 1, 이음선 쪽 바깥면 — 판 두께·귀퉁이 R − 0.5 까지)을 따로 정한다. 아래 표는 끼움형 기준.

| 부품 | 내용 |
|---|---|
| 뚜껑 `Lid` (3mm) | 통 윗구멍에 끼우는 판(틈 `FIT` 0.2, 모서리 기둥 윗면에 얹혀 볼트 4개). SMA 홈 윗부분은 뚜껑의 혀가 메운다. C6L(레고 핀 2개 Ø4.9 — 고정은 아래 '통'의 누름 받침과 안테나 조임)·버튼 PCB(M3 인서트 기둥 4개)를 밑에 매단다. OLED 둘레는 1mm 로 얇고 45° 경사(화면 마스크), C6L 버튼은 Ø3 드라이버 구멍, 버튼 구멍은 양 끝 2개(가운데는 `MID_KEY`). 모서리 볼트 4개(머리 자리 파기) |
| 통 `Body` | 바닥~윗면 옆벽 전부(옆면에 이음선 없음) + 가운데 격판. 격판 위 누름 받침 4개가 뚜껑을 닫으면 C6L 을 0.3mm 눌러 뚜껑과 사이에 끼운다(`C6L_PRESS`). C6L 의 SMA 끝은 -X 벽에 붙어, 안테나를 조이면 벽을 사이에 두고 당겨진다. 위 칸 = 전자부, 아래 칸 = 배터리. 모서리 기둥: 위 = M3 인서트, 아래 = 자석. -X 벽은 안테나 지름(Ø10)만큼 바깥에서 파서 1mm, SMA 홈은 위가 열려 뚜껑째 내려 끼운다. 격판에 패널형 USB-C 자리(몸통 구멍 + M2 인서트 2개, 플랜지는 배터리 쪽) |
| 자석 바닥 `Cover` | 통 아랫구멍에 끼우는 판 + 모서리 자석 기둥(`SEAM_H`). 바닥판 반달 손가락 구멍(반지름 `NOTCH_R` 7, 곧은 변 중심 `PULL_X/PULL_Y` — 평면도에서 드래그, 둥근 쪽 방향 `PULL_DIR`, 바깥 모서리 0.8 모따기, 바닥판 가장자리·자석 기둥에 걸리면 오류) — 곧은 변에 손끝을 걸어 당겨 뗀다(옆으로 튀어나온 혀는 부러지기 쉬워 없앰). 떼어 배터리를 넣고 뺀다 |

- 그립: 바깥은 외피 하나(세로 모서리 `R_OUT` 7 + 윗면 테두리 `TOP_R` 3.5 + 아랫면 테두리 `BOT_R` 3.5). 옆면은 통이 전부 갖고, 끼우는 뚜껑·바닥 판도 같은 외피로 잘라 테두리 곡면이 윗면·아랫면에서 이어진다. 테두리 R 은 세로 R 보다 작게(브라우저: 원기둥 + 모서리 1/4 토러스, Fusion: 둥근 상자에 필렛 기능), 벽이 1.2mm 아래로 얇아지거나 뚜껑 볼트 머리 자리가 곡면에 걸리면 경고.
- 배터리는 통의 벽 안에 들고 +X 멈춤턱 2개(앞·뒤 벽 쪽, 가운데는 케이블 길)와 -X 모서리 기둥이 위치를 잡는다. 앞·뒤 벽의 누름 리브 4개(끝 R1.5, `RIB_PRESS` 0.3mm 파고듦, 아래 2mm 는 조임 0 으로 시작)가 배터리를 마찰로 잡아 바닥을 떼도 통에 남는다. 바닥 자석 기둥 높이 `SEAM_H` 기본 4(바닥판 위, 통 기둥 밑면과 자석끼리 붙음).
- 출력: 통은 격판이 가운데 떠 있어 배터리 칸 또는 전자부 칸에 서포트가 필요하다. 뚜껑은 뒤집어서, 바닥은 판을 아래로 서포트 없이.
- 배터리는 -X 쪽, +X 쪽에 케이블 자리(`CABLE_BAY`) — USB-C 커넥터는 배터리 밖에 있어야 아래에서 케이블을 꽂을 수 있다(겹치면 오류).
- 배터리 → C6L 전원 경로(`USB_MODE`, 셀렉트): ⓪ **뚜껑 밑에 세운 USB-C(기본)** — 뚜껑 밑에 매단 받침벽(격판 위 0.5 띄움, 커넥터는 격판과 뚜껑 사이 가운데, 뚜껑과 함께 열리므로 배터리 케이블이 뚜껑을 들 만큼 길어야 한다. `USBW_T` 5, 뒷면 양끝 리브 6×3 이 꽂을 때 미는 힘을 받는다)에 커넥터를 90° 로 세워 볼트 2개로 옆에서 고정(M2 인서트). 케이블 구멍(`CBL_L`×`CBL_W`, `USBC_CX/CY`)과 받침벽(커넥터 면 중심 `USBW_CX/CY`)은 따로 위치를 잡고(평면도에서 각각 드래그), 플랜지 면은 자동으로 구멍 쪽을 본다. 뚜껑을 열고 배터리 케이블 플러그를 구멍으로 올려 옆으로 꽂는다. 받침벽이 C6L/PCB 와 겹치거나 전자부 높이가 플랜지 7 + 1 보다 낮으면 오류, 구멍이 커넥터 정면에서 벗어나거나 가까우면 경고 ① 격판에 패널형 USB-C 커넥터(밑에서 꽂음) ② 격판에 케이블 구멍(양끝 둥근 14×8) — 배터리 케이블을 C6L USB-C(+Y 쪽 긴 면, Grove 끝에서 20.3)에 바로 꽂는다. C6L 옆 플러그 자리(`PLUG_L`, ㄱ자 플러그 기준 12)가 막히면 오류 ③ 없음.
- 안테나(참고 부품 `REF_antLoRa`·`REF_antWiFi`, 출력 안 함): 부속 RP-SMA 휩 — LoRa 868MHz 108mm 는 앞(−Y) SMA, Wi-Fi 2.4GHz 84mm 는 뒤(+Y) SMA(docs.m5stack.com U202 사진·사양). 길이와 꺾음(90° 세움·45°·곧게) 선택.
- 버튼 PCB 회전(`PCB_ROT` 0·90·180·270, 헤더 위치는 평면도의 점). 90°·270° 는 PCB 길이 66.04 가 기본 안쪽 깊이 66 보다 길어 `EXTRA_Y` 로 깊이를 늘려야 들어간다.
- 버튼 모듈은 ST003(AliExpress 1005009436136022). 사진상 헤더 핀·POWER LED 가 위로 솟고 둥근 캡(약 Ø11.5)이 끼워져 있다 — 핀은 빼고 선 직결, 캡을 쓰면 `BTN_HOLE_D` 12.5·`SW_H` 는 PCB~캡 끝 실측.
- 필요 인서트·볼트·자석 수량과 볼트 길이는 화면 "필요 부품" 표가 계산한다(기본: M3 L5.7 ×4, M3 L4 ×4, M2 L3 ×2, 자석 Ø6×3 ×8).

## 파일

| 경로 | 내용 |
|---|---|
| `core.js` | 단일 진실: 파라미터(`DEFS`) → 배치 → 경고 → CSG 트리(box/cyl/frustum/torus/add/sub/and) |
| `csg.js` | 트리 → manifold-3d 3.5.4 메시, 바이너리 STL |
| `app.js`, `index.html`, `style.css` | 화면(플라이트 케이스 설계 앱과 같은 틀, three.js). 사이드바: 맨 위 검색 칸(이름·키, Esc 로 지움, 안 쓰는 항목도 흐리게 보임), 묶음 접기(접힘 상태 기억, 제목 옆 마지막 case.json 저장 이후 수정한 개수 — 수정한 값은 분홍색), 지금 고른 결합 방식·USB-C 방식에서 안 쓰는 항목 숨김(`USE`). 평면도에서 C6L(Y)·PCB·USB-C 드래그, 위치 항목의 "X·Y 가운데" 버튼으로 안쪽 공간 가운데 정렬 |
| `check.mjs` | `node case/check.mjs` — 기본값 오류 0, 세 부품 부피, 슬라이더 양 끝 계산, `C6LCaseBuild/c6l-case.json` 갱신 |
| `C6LCaseBuild/` | Fusion 스크립트. `c6l-case.json`(이 폴더 또는 ~/Downloads 중 최근 것)의 트리를 TemporaryBRepManager 로 계산, 사각뿔대는 테이퍼 압출, 둥근 외피는 필렛 기능. 완료 창에 부품별 치수·부피 |

## Fusion

1. 맥에서 스크립트 받기(109 서버에서 Fusion Scripts 폴더로, 한 번만 — 스크립트가 바뀌면 다시):

```bash
D="$HOME/Library/Application Support/Autodesk/Autodesk Fusion 360/API/Scripts/C6LCaseBuild"; mkdir -p "$D" && for f in C6LCaseBuild.py C6LCaseBuild.manifest c6l-case.json; do curl -fsSo "$D/$f" "http://192.168.1.109:8817/C6LCaseBuild/$f"; done
```

2. 툴에서 **case.json 저장** → `~/Downloads/c6l-case.json`(브라우저가 붙인 `c6l-case (1).json` 도 찾는다, 가장 최근 것을 쓴다).
3. Fusion **Shift+S** → `C6LCaseBuild` 실행 → 새 문서에 Lid·Body·Cover·REF_ 부품, `out/` 에 STL.

## 치수 출처·가정

- C6L: docs.m5stack.com U202 Model Size(24×56×8, SMA 간격 14, Ø5 레고 구멍 16 간격·끝에서 12). OLED·버튼 위치는 도면 비례 측정.
- 버튼 PCB: 첨부 도면(구멍 간격 59.944×16.764). 키 X 는 비례 측정(피치 20.32).
- USB-C 커넥터: 사진 치수(플랜지 20×7, 몸통 폭 9). 구멍 간격 16.5·몸통 두께 3.6·길이 5.3 은 사진 비례 추정.
- 가정값: 택트 스위치 12×12×7.3, SMA 중심 = 앞면에서 5mm, 안테나 지름 10, 인서트 구멍(M3 Ø4.0, M2 Ø3.2)은 일반 권장값 — 쓰는 인서트 규격에 맞춰 바꿀 것.
- Fusion 실행은 아직 검증하지 않았다(2026-11-09, Fusion MCP 미연결).
